# Vue 练习清单

按 README 中的学习顺序完成练习，并手动确认页面行为。

- [ ] 响应式：修改输入后，观察 ref、reactive 和 computed 的结果。
- [ ] 表单：尝试前后空格和数字输入，观察 .trim 与 .number 的效果。
- [ ] 组件通信：修改子组件输入，确认父组件通过事件或 v-model 收到更新。
- [ ] 依赖注入：观察 provide / inject 如何在组件之间共享数据。
- [ ] 生命周期：挂载、更新和卸载组件，观察对应回调。
- [ ] DOM 更新：比较修改状态后立即读取 DOM 与等待 nextTick 后读取的结果。
- [ ] 逻辑复用：阅读组合式函数，识别状态、派生值和对外提供的方法。
- [ ] 持久化：将任务列表保存到 localStorage，刷新页面确认恢复结果。

每完成一项，记录操作步骤、预期行为和实际结果，方便回顾。
