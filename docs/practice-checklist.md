# Vue 练习清单

按照 [项目说明](../README.md) 的模块顺序练习，每完成一项后在浏览器中检查交互结果。

## 响应式基础

- [ ] 使用 `ref` 和 `reactive` 修改状态，观察页面更新。
- [ ] 使用 `computed` 实现全部、已完成、未完成任务的筛选。
- [ ] 比较 `watch` 与 `computed` 的用途。
- [ ] 验证表单绑定的 `.trim` 和 `.number` 修饰符。

## 组件通信

- [ ] 通过 `props` 向子组件传递数据。
- [ ] 通过 `emit` 通知父组件处理交互。
- [ ] 练习组件上的 `v-model`。
- [ ] 使用 `provide` / `inject` 传递共享数据。

## 生命周期与逻辑复用

- [ ] 观察挂载、更新和卸载时的行为。
- [ ] 使用 `nextTick` 读取更新后的 DOM。
- [ ] 练习 `Transition` 的进入和离开效果。
- [ ] 将可复用状态逻辑提取为组合式函数。
- [ ] 使用 `localStorage` 保存数据，并刷新页面检查恢复结果。
